Write engine/params.py for the NetArchitect project (Python 3.10+, standard library
only, same Decision / error classes as before, errors in engine/errors.py).

Functions:
- load_preset(name: str) -> dict. name is one of "campus_lan", "metro_man",
  "global_wan"; reads presets/<name>.json relative to the repository root (use
  pathlib and __file__, not the current working directory). Unknown name raises
  InvalidParameterError listing the valid names.
- load_custom(path: str) -> dict. Reads a JSON file, then validates it.
- validate_params(params: dict) -> dict. Validates and returns the dict; raises
  InvalidParameterError with a clear message naming the offending key.

The JSON schema (see the example below) has these keys:
profile (int), name (str), endpoints (positive int), root_cidr (str),
resiliency ("none" or "dual-homed"), routing (object with num_sites,
multi_cloud, num_autonomous_systems), links (non-empty list of objects with name
and distance_m), subnets (non-empty list of objects with name and hosts).

Validation rules:
- all keys are required; unknown extra keys are rejected
- numeric fields must be real numbers or ints as appropriate, never bool, NaN,
  infinite, zero, or negative
- hosts and endpoints must be integers
- subnet names must be unique and non-empty
- root_cidr must be a string; do not validate its format here (the VLSM engine does)
- routing.multi_cloud must be a bool

Reply with only the complete file in one code block.
