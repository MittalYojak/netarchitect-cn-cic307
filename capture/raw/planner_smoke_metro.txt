3. Topology tier
----------------
Choice: Full-mesh site interconnect
Justification: The network has 450 endpoints across 3 sites. A network with 450 endpoints across 3 sites requires 3 inter-site links in a full mesh. This topology provides direct connectivity between every pair of sites, reducing dependence on intermediate sites and supporting efficient inter-site communication. Direct inter-site connections improve path diversity and limit the impact of an individual inter-site link failure. Dual-homed resiliency provides redundant uplinks or network paths. Access switches should connect to independent distribution or collapsed-core devices where applicable. For multi-site topologies, redundant inter-site or WAN paths should be provisioned to maintain connectivity during individual link or device failures. The selected resiliency level is 'dual-homed'.
References: None

4. Routing protocol
-------------------
Choice: Multi-Area OSPF with Area 0 backbone
Justification: The network has 9 subnets across 3 sites, does not use multiple cloud providers, and operates within 1 autonomous system. Multi-area OSPF is recommended to isolate routing domains while maintaining connectivity through the Area 0 backbone. Area boundaries support route summarization, reduce routing overhead, and improve scalability.
References: RFC 2328
